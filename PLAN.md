# Elena's BFA Dance Admissions Tracker — `galithoc/elena-universities`

## Context

Elena Stewart (16, elite competition dancer — contemporary/lyrical + jazz/commercial, TC The Company, Puerto Rico) is HS class of 2027, applying **this fall (2026)** for **Fall 2027 entry** to **9** BFA dance programs: Fordham/Ailey, NYU Tisch, Pace, University of Arizona, Chapman, SUNY Purchase, Boston Conservatory at Berklee, USC Glorya Kaufman, and **Marymount → Northeastern University – New York City** (added at George's request). More schools may be added.

George wants one place that pulls together every school's admissions process — deadlines by round, prescreen/audition requirements, scholarships/aid, essays/recs, program comparison — that **he can add to manually** and that **AI keeps current automatically** as schools publish 2027-28 specifics (most roll out Aug–Oct 2026; Common App opens Aug 1, 2026 — three weeks away).

Two hard realities shape the design:
1. **Data freshness is the core problem.** In July 2026 many facts are still last-cycle's. Every dated fact carries provenance (source URL, last-verified date, `confirmed 2027-28` vs `carried from 2026-27` vs `TBD` badge) and an AI refresh loop re-checks official pages and upgrades facts as they publish.
2. **Puerto Rico home base.** Every audition is a flight from SJU. Virtual-audition options, East-Coast regional dates, and clustering the five NYC-area schools (Fordham/Ailey, Tisch, Pace, Purchase, Marymount/Northeastern) into single trips are first-class features. Timezone `America/Puerto_Rico` (AST, UTC−4, no DST). Elena is a US domestic applicant; FAFSA applies.

### Decisions made by George (via Q&A)
- **Platform:** GitHub Pages static site from this repo. Data = JSON in the repo; every edit/refresh is a commit; site auto-updates. Public URL but noindex + no sensitive personal data.
- **AI freshness:** BOTH on-demand (repo skill `/refresh-admissions` in a Claude Code session) and scheduled (weekly GitHub Action with `ANTHROPIC_API_KEY` secret, proposing changes as a PR).
- **Coverage:** everything — deadlines, audition/prescreen detail, scholarships & aid, academics & essays, program comparison.
- Deep research on all 9 schools was run during planning (results below in §Research); its findings become the initial dataset.

### Reuse from `tc-nationals-2026` (George's prior app, same design DNA)
- Dark "editorial" design system from `build_tc_search.py:21-242` — CSS custom properties, Fraunces + Archivo (base64 `fonts.css`), card/pill components, film-grain background, reduced-motion + print styles. "STEW-ART Designs" credit.
- Vanilla-JS engine patterns from `build_tc_search.py:296-683` — date parsing/sorting, `.ics` export (`buildICS`), `esc()`, toasts, localStorage, filters, sticky mobile controls.
- Taste: **no frameworks, no npm/bundler**; vanilla HTML/CSS/JS; Python (stdlib) scripts; noindex/private-feeling.
- Difference vs TC app: data is **NOT inlined** — it lives in `data/*.json` fetched at runtime (relative paths), so AI refreshes edit data without touching app code and there is no build step.

**Pre-flight caveat:** GitHub Pages on a **private** repo requires a paid GitHub plan. If the repo is private on a Free account: make it public (privacy posture: noindex meta + robots.txt disallow, no PII beyond schedule/progress statuses, no essay text in notes) or upgrade. Check first during implementation.

### Data model (key ideas)

**`Fact` object** — every dated/sourced leaf value is wrapped:
```json
{ "value": "2027-01-15", "sourceUrl": "https://…", "lastVerified": "2026-07-10",
  "cycleStatus": "carried_from_2026", "note": "…", "pendingChange": null }
```
- `cycleStatus`: `confirmed_2027` | `carried_from_2026` | `tbd` (value null). Upgrade to confirmed **only** when the page explicitly references Fall 2027 / the 2026-27 cycle.
- `pendingChange` = never-silently-change rule: a refresh that finds a conflict with a stored `confirmed_2027` value writes `{proposedValue, sourceUrl, seenOn, note}` + a changelog `proposed` entry; UI shows red "confirm needed"; a human accepts via a Claude session.

**School file `data/schools/<slug>.json`** (schemaVersion, id=slug): identity (name, institution, degree, city/region, accent color, campusTimezone, applicationSystem); `sources[]` — the official URLs to re-crawl, each with `checkFor[]` hints; `rounds[]` (id, type ED/ED2/EA/REA/RD/priority/rolling/scholarship_priority, academicDeadline/artsSupplementDeadline/decisionRelease Facts); `artisticSupplement` (portal, portalUrl, fee, deadline, prescreenRequired, `videoSpec.value[]` itemized spec lines with ids); `auditions[]` (id, label, format in_person|virtual|hybrid|prescreen_only, city, date Fact, timezone, registrationOpens/Deadline Facts, registrationUrl, status tbd|announced|open|registered|full|completed|cancelled); `academics` (testPolicy, recommendations, `essays.value[]` prompts with ids/wordLimit, interview); `scholarships[]` (kind talent|merit, amount/deadline Facts, requiresSeparateApp); `financialAid` (fafsaRequired, cssProfileRequired, cssCode, priorityDeadline); `costs`; `programFacts` (cohortSize, acceptanceRate, genreEmphasis[], companyAffiliation, notable).

**`meta.json`**: app title ("Elena — Road to the BFA"), cycleLabel, student (name, home PR, timezone, genres), cycle anchors (commonAppOpens 2026-08-01, fafsaOpens 2026-10-01), `schools[]` manifest of all **9** (fetch list + display order), `regions` clusters — nyc: [fordham-ailey, nyu-tisch, pace, suny-purchase, marymount-northeastern] "several in one trip", socal: [usc-kaufman, chapman] "~40 mi apart", boston, tucson — ics config, lastRefresh.

**`progress.json`** (family-owned; refresh flows NEVER touch it; seeded for all **9** schools): `global.checklist[]` (FAFSA, CSS, Common App account/essay) + per-school `{roundChoice, status active|applied|admitted|denied|waitlisted|withdrawn, checklist[] (10 seed items: supp essays, recs, prescreen filmed, prescreen submitted, app submitted, audition registered, travel booked, audition done, aid docs, decision), notes[]}`. Item: `{id, label, status todo|in_progress|done|blocked|na, owner elena|parents|both, due, note, doneOn}`. Custom items = new `custom-*` ids.

**`changelog.json`**: append-only, append at end; entry `{id, date, school, type confirmed|changed|new|proposed|resolved|added_school|note, text, refs[], by}`.

**Data contract (goes in CLAUDE.md):** never reuse/renumber/delete ids; never delete facts/events (supersede or `cancelled`); every material change ships a same-commit changelog entry; refresh edits only `data/schools/*` + `changelog.json` + `meta.lastRefresh`; app/family edit only `progress.json`; serialization = 2-space indent, UTF-8, `ensure_ascii=False`, trailing newline (identical diffs from Python/JS/hand edits); dates ISO YYYY-MM-DD; the JS extractor `collectDatedItems()` and Python `build_ics.collect_items()` mirror each other — kind list documented here.

### ICS feed — `scripts/build_ics.py`
Python mirror of the JS extractor; deadlines = all-day VEVENTs with VALARMs at −7d/−1d; timed auditions use campus TZID; carried facts get "[unconfirmed — last year's date]" in SUMMARY; tbd skipped; kind prefixes ⏰🎬✈️💰. **Stable UIDs** `{schoolId}-{itemId}@elena-universities` so subscribed phones update in place; `DTSTAMP` = fact's lastVerified → fully deterministic output → CI `--check` byte-compares. Headers: X-WR-CALNAME "Elena — College Deadlines", X-WR-TIMEZONE America/Puerto_Rico, REFRESH-INTERVAL PT12H; RFC 5545 75-octet folding. `build-ics.yml` regenerates+commits on any data/** push, so the feed can never go stale however data was edited. (Note in-app: Google polls feeds every ~12–24h.)

### Refresh mechanics — ONE drill, two entry points
**`.claude/skills/refresh-admissions/SKILL.md`** (args: optional school slug; `--mode=pr`): 1) read meta + school files, worklist = all `sources[].url` (+ fact sourceUrls), cap ~3–6 fetches/school; 2) WebFetch & extract candidates per `checkFor`; 3) decision table — tbd/carried + page value → set value/lastVerified (confirm only with explicit 2027 evidence); same value → bump lastVerified; conflict with confirmed_2027 → `pendingChange` only; audition vanished → status cancelled; never invent URLs; ambiguity → pendingChange + note quoting the page; 4) changelog entries (human sentences); 5) meta.lastRefresh; 6) `validate.py` must pass; 7) `build_ics.py`; 8) commit to main, or `--mode=pr` → branch `refresh/YYYY-MM-DD` + PR with old→new summary table; nothing changed → bump lastRefresh only, no PR. Hard-rules box: never touch progress.json, never delete ids, serialization, evidence bar.

**`weekly-refresh.yml`**: cron `0 10 * * 1` (Mon 6 AM AST) + workflow_dispatch; `anthropics/claude-code-action@v1` with `ANTHROPIC_API_KEY` secret, prompt "Run the refresh-admissions skill in --mode=pr…", `--max-turns 100`, pin a Sonnet model for the mechanical drill; concurrency group; timeout 30 min; permissions contents+PRs write. Cost ≈ $1.5–4/run (~$6–16/mo weekly); George can bump to 2×/week Aug–Oct by editing one line. `validate.yml` gates the PR regardless of what the model did. (Verify exact action input names against the pinned @v1 README at implementation.)

**`.claude/skills/add-school/SKILL.md`**: slug → copy `_template.json` → research official pages, fill Facts with provenance (same evidence rules) → populate `sources[]` → append to `meta.schools` → seed progress checklist (10 items) → changelog `added_school` → assign accent + region → validate → ICS → commit.

### Validation — `scripts/validate.py` (stdlib only)
Errors (exit 1): parse failures; id≠filename; manifest↔files bijection; enum violations; non-tbd Fact missing value/sourceUrl/lastVerified; bad ISO dates; lastVerified in future; duplicate ids in scope; progress keys not in manifest; roundChoice not a valid round id; pendingChange shape. Warnings (`::warning::` in Actions): past-dated deadline whose checklist item isn't done/na; confirmed facts unverified >45 days; roundChoice null after Sept 1; tbd deadlines <60 days out. `validate.yml` runs it + `build_ics.py --check` on PRs and pushes (python3 preinstalled on ubuntu-latest; no setup step).

## Research findings (Fall 2027 landscape for the 9 schools)

**Status & caveat:** All **9 schools** are now researched (the original deep-research run covered 5; three targeted follow-up agents covered Arizona, Chapman, SUNY Purchase, and the newly-added **Marymount → Northeastern** merger). Almost everything is **snippet-sourced** — most schools' `.edu` origins block automated fetchers (HTTP 403), so wording came from search-result summaries of the official pages and needs a browser spot-check. Only 1 claim was formally vote-confirmed before the research run's usage limit hit; treat the rest as **extracted-but-not-triple-verified**, and nearly all reflect the **Fall 2026 cycle** (pages not yet updated for 2027). This is precisely the `carried_from_2026` seed state the app is built for — **the first `/refresh-admissions` run re-verifies everything against a real browser and upgrades to `confirmed_2027` where pages have updated.** Every fact enters the dataset with its official `sourceUrl`, `lastVerified: 2026-07-10`, and `cycleStatus: carried_from_2026` (or `tbd`). A few dates *are* already confirmed for Fall 2027 (Arizona EA Nov 1 + 2026-27 tuition; Chapman's Nov 1 / Jan 15 rounds) and seed as `confirmed_2027`.

**Cross-cutting insights (drive the app's headline features):**
- **The fall crunch is Nov 1 → Dec 1.** Nov 1 recurs across almost every school (Fordham + Ailey both apps, Tisch ED1, Pace ED, Boston EA, **Arizona EA, Chapman EA/ED1, likely Northeastern/Marymount**); Dec 1 is the pivotal prescreen/final date (USC portfolio, Pace final app, Boston RA). The "Next Up" dashboard must make this pileup unmissable.
- **Genre-fit is a real axis — surface it (matrix in Compare view).** Strong **jazz/commercial** fits: **Pace** Commercial Dance BFA, **Boston Conservatory** Commercial Dance BFA (75-min jazz + freestyle audition), **Arizona** (triple-track ballet/modern/jazz with an explicit *Commercial Dance* pathway + Gus Giordano jazz lineage), **Marymount/Northeastern** (ballet/jazz/contemporary + *commercial jazz* coursework), **Chapman** (ballet/jazz/modern + LA agency connections). **Ballet/contemporary-leaning** (weaker commercial fit): **Tisch** (prescreen has *no* jazz section), **USC Kaufman** (portfolio has *no* barre; hybrid ballet/contemporary), **SUNY Purchase** (ballet+modern conservatory; **audition solo may not be jazz** — jazz is electives only). For a versatile competition dancer, Arizona / Pace / Boston-Commercial / Marymount are the sweet spot.
- **Virtual-audition matrix (decisive for a San Juan applicant — every in-person date is a flight):** available at **Tisch** (virtual callback), **Boston Conservatory** (live-online), **Pace** ("limited number of virtual auditions"), **Arizona** (video-only accepted — *but* see the catch below), **Chapman** (virtual live audition after a required video prescreen). **On-campus-effectively-required:** **SUNY Purchase** (video route only advertised to international applicants — a domestic PR applicant must email `dance@purchase.edu` to confirm eligibility), **USC Kaufman** (live audition on-campus in LA after prescreen), **Fordham/Ailey** (in-person NYC/tour after invite). **Marymount/Northeastern** historically had a video route — *unconfirmed post-merger.* The **Travel view** ranks schools by "can she avoid the flight?"
  - **Arizona catch worth its own flag:** video-only auditioners are **not eligible for the first-year Dance Merit (talent) scholarship** — only in-person (before ~Feb 1) auditioners are. So one Tucson trip (ideally the mid-Sept Arizona Jazz Dance Showcase audition) trades a flight for talent aid. This is a per-school note, not a global rule.
- **NYC cluster is now FIVE schools:** Fordham/Ailey, Tisch, Pace all audition in NYC (Jan–Mar); **SUNY Purchase** is Westchester (~35 min from Grand Central, on-campus only); **Marymount/Northeastern** is Upper East Side. One or two well-timed NYC trips can cover several in-person auditions — the app's Travel view exists to line these dates up.
- **Puerto-Rico cost realities (flag in the aid/cost view):** **SUNY Purchase** charges PR residents **out-of-state** (~$19.6K vs $9K tuition; ~$41K COA) and they're **ineligible for NY TAP/Excelsior** — its famous affordability does *not* apply. **Arizona** non-resident is confirmed **$44,338 tuition+fees** (~$60K COA) but offers **automatic non-resident academic merit** ($4K–$20K) that softens it. **Chapman** (~$88–94K COA, no CSS, FAFSA-based) and **Marymount/Northeastern** (cost may jump from MMC's ~$61K toward Northeastern's ~$85K, **and Northeastern newly requires the CSS Profile**) are the high-sticker options. FAFSA applies everywhere; **CSS Profile is required at USC, Northeastern/Marymount** (verify each).
